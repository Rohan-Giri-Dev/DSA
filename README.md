- Arrays

  - Two Sum, stock buy/sell, and majority element
  - Kadane's algorithm and subarray problems
  - Matrix rotation, spiral traversal, and Pascal's triangle
- Recursion
  - Factorial and Fibonacci sequence
  - Reversing arrays and numbers
  - Palindrome checks
- Hashing
  - Frequency counting with arrays and maps
  - Character hashing
- Sorting
  - Bubble sort
  - Selection sort
  - Insertion sort
  - Merge sort
  - Quick sort
  - Recursive sorting implementations
- Binary search
  - One-dimensional binary-search problems
- Additional practice
  - Easy, medium, and hard problems
  - LeetCode exercises

## Getting Started

### Prerequisites

Install a C++ compiler with C++11 support or newer, such as:

- [GCC / MinGW-w64](https://www.mingw-w64.org/)
- [Clang](https://clang.llvm.org/)
- [Microsoft Visual C++](https://visualstudio.microsoft.com/vs/features/cplusplus/)

### Compile and Run a Solution

Clone the repository:

```bash
git clone https://github.com/Rohan-Giri-Dev/DSA.git
cd DSA
```

Compile an individual file with `g++`:

```bash
g++ -std=c++17 "Sorting/quick_sort.cpp" -o quick_sort
```

Run it on Windows:

```powershell
.\quick_sort.exe
```

On Linux or macOS, run:

```bash
./quick_sort
```
